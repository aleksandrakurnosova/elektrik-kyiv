ВОЛЬТ — статичний односторінковий сайт

Файли:
- index.html — структура та весь український текст;
- style.css — дизайн і адаптивність;
- script.js — галерея з відкриттям фото та демонстраційна поведінка форми;
- images/ — шість тимчасових зображень для галереї.

Перед запуском:
1. Замініть телефон +38 (000) 000-00-00 у index.html.
2. Замініть hello@volt-service.ua на реальну пошту.
3. Замініть файли images/work-01.svg — work-06.svg реальними фото або змініть шляхи в index.html.
4. Підключіть форму до пошти, Telegram чи CRM: зараз вона лише показує повідомлення про успішне надсилання.

Для перевірки відкрийте index.html у браузері. Для публікації завантажте весь вміст папки на хостинг без зміни структури.
